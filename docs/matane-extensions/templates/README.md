# Matane Extensions

Official extensions for [Matane](https://github.com/SukunDev/matane), the open-source desktop manga reader.

This repository is **added to Matane by default**. Extensions from it show as **Official · Verified**: every index is signed with the official key built into the app, and every archive must match the SHA-256 in that signed index before it is installed.

**Repository URL:** `REPO_URL` (for other apps or to add it again: Extensions → Repositories → Add repository)

|---|---|---|
| MangaDex | EN, ID | https://mangadex.org |

## Something broke?

Sites change. A smoke test reads every site once a day and opens an issue when an extension breaks. Before opening a new issue, check whether there is one already; otherwise include the extension, the manga and what you did.
