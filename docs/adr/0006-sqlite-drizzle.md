# 6. SQLite via better-sqlite3 and Drizzle

Status: Accepted (2026-09-23)

## Decision
One SQLite file (`userData/data.db`, WAL, foreign keys on) accessed from main through Drizzle ORM (snake_case columns). The full schema from BRAINSTORM.md §7 exists from day one, including tracker tables and FTS5 `manga_fts` (custom migration with sync triggers). Migrations are generated by drizzle-kit, shipped in `apps/desktop/drizzle/`, and an automatic backup (last 3) is taken before migrating an existing database.

## Consequences
`better-sqlite3` is native: it is rebuilt for Electron on `postinstall`, and tests run under `ELECTRON_RUN_AS_NODE=1 electron vitest` so the ABI matches. Queries run synchronously in main, so they must be indexed; heavy jobs go to worker threads.
