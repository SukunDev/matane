# Reader

## Modes

| Mode     | What it does                                                                |
| -------- | --------------------------------------------------------------------------- |
| Single   | One page at a time                                                          |
| Double   | Two pages side by side (shift by one if the spreads are off)                |
| Webtoon  | One continuous strip without gaps, for manhwa and manhua                    |
| Vertical | Pages one under another, with a gap                                         |
| Auto     | Picks from the kind of manga: manga as right-to-left pages, manhwa as strip |

What **Auto** means for each kind of manga is set in **Settings → Reader → By type**. The reader menu (the gear in the reader) changes the mode, direction and fit **for the manga you are reading**; Settings → Reader sets the defaults.

## Keys

| Action                       | Default keys                                     |
| ---------------------------- | ------------------------------------------------ |
| Next / previous page         | <kbd>Page Down</kbd>, <kbd>Space</kbd> / <kbd>Page Up</kbd>, <kbd>Shift</kbd>+<kbd>Space</kbd> |
| Page to the right / left     | <kbd>→</kbd>, <kbd>D</kbd> / <kbd>←</kbd>, <kbd>A</kbd> (follows the reading direction) |
| Scroll down / up             | <kbd>↓</kbd> / <kbd>↑</kbd>                      |
| First / last page            | <kbd>Home</kbd> / <kbd>End</kbd>                 |
| Next / previous chapter      | <kbd>]</kbd> / <kbd>[</kbd>                      |
| Full screen                  | <kbd>F</kbd>                                     |
| Show or hide the menu        | <kbd>M</kbd>                                     |
| Close the reader             | <kbd>Esc</kbd>                                   |
| Auto-scroll (strip)          | <kbd>S</kbd>                                     |
| Zoom in / out / reset        | <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>Ctrl</kbd>+<kbd>-</kbd> / <kbd>Ctrl</kbd>+<kbd>0</kbd> |

Every key can be changed in **Settings → Reader → Keyboard shortcuts**: click **+** next to an action and press the key (with <kbd>Ctrl</kbd>, <kbd>Alt</kbd> or <kbd>Shift</kbd> if you like). A key can belong to one action only.

## Mouse and touch

- **Tap zones:** clicking the left, middle or right part of the page turns pages or shows the menu. Settings → Reader has several layouts with a preview, and can invert them.
- **Scroll wheel:** scrolls tall pages, then turns the page at the edge (can be turned off).
- **Zoom:** <kbd>Ctrl</kbd>+scroll or double-click in page modes; drag to move around a zoomed page. In the strip, zoom changes the strip width.
- **Touch screens:** swipe to turn pages, pinch to zoom, tap as with the mouse.

## Display

- **Colour filters:** brightness, contrast, warm tint, grayscale and invert, plus a custom background colour. Like other reader settings, they can be set per manga.
- **Crop borders** trims plain white or black margins off pages; **Split tall pages** shows very long strips in parts so they scroll smoothly. Your downloads are not changed.
- **Page number** shows "page / total" while the bars are hidden.
- **Auto-scroll** moves the strip by itself (<kbd>S</kbd> or the button in the bottom bar; set the speed in Settings). It pauses when you click, press <kbd>Space</kbd> or switch to another window, and stops at the last chapter.

## Pages

Right-click a page to **Save image…**, **Copy image** or **Set as cover**. At the end of a chapter the next one loads; Matane warns when chapters seem to be missing in between.
